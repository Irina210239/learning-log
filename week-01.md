Command	What it does
pwd	shows where you are
ls	lists what is inside the folder
cd folder	moves inside the folder
cd ..	goes up one folder
mkdir name	makes a new folder
touch name	makes a new, empty file
cp old new	makes a copy (you end up with two files)
rm name	deletes the file, with no undo
mv old new	renames or moves (you end up with one file)
open .	opens the current folder in Finder
python3 --version	shows whether Python is installed, and which version
python3 hello.py	runs the file, top to bottom
